# Radio Fundamentals

Everything an antenna, a feedline, or a receiver does comes down to a few ideas about signals: how fast they alternate, how long each wave is, and how strong they are compared with something else. This topic covers that theory, the radio-specific part of the Basic exam's sections B-004 and B-005.

It starts where [Start Here](start_here.md) leaves off. The electricity underneath, from voltage to capacitors and inductors, lives on [Exploring Electronics](https://electronics.bradpenney.io/); these articles link to it rather than repeat it.
